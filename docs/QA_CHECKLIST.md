# LOOKFIT QA 체크리스트

앱 전체(메인 · 체형 · 옷장 · 탐색 · 상품 상세 · 장바구니 · 퀘스트 · 설정 · AR 피팅룸)를 릴리스 전에 확인하는 목록입니다.
자동화 가능한 항목은 스크립트로 검증하고, 사람이 봐야 하는 항목은 `수동`으로 표시했습니다.

## 실행 방법

| 스위트 | 명령 | 범위 |
| --- | --- | --- |
| jsdom 기능 QA | `node scripts/qa-mvp.js` | 데이터 계약, 동작 로직, 마이그레이션, 초기화 (82개) |
| 화면 감사 | `node scripts/qa-audit.js` | 실제 Chrome에서 전 화면 순회, 레이아웃 넘침·깨진 이미지·작은 터치 영역·토스트 잘림, 새로고침 유지 (71개) |
| AR E2E | `node scripts/e2e-ar.js` | 가짜 웹캠(y4m)으로 카메라 추적, FPS, 사이즈 메쉬, 사진/샘플 모드, 캡처, 카메라 해제 (19개) |
| 소매 시각 점검 | `node scripts/probe-arms.js g012` | 팔 포즈 4종(기본/들기/T자/굽힘) 캔버스 캡처 |

화면 감사와 AR E2E는 `puppeteer-core`가 필요합니다(기본 위치 `~/.lookfit-tools/node_modules`). 스크린샷은 `~/.lookfit-tools/audit`, `~/.lookfit-tools/shots`, `~/.lookfit-tools/arms`에 저장됩니다.

## 알려진 한계

- 실사 누끼 의상(p01–p07)은 소매가 몸통과 한 장이라 팔 추적 대상이 아닙니다. 생성 의상 중 소매가 있는 상의만 소매가 따로 움직입니다.
- Decart AI 실사 모드는 시연용으로 API 키를 기기에 저장합니다. 실제 서비스는 서버에서 단기 client token을 발급해야 합니다.
