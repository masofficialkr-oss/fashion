# LOOKFIT QA 체크리스트

앱 전체(홈 · 탐색 · 상품 상세 · 장바구니 · AR 탭(가상 시착 / 체형 측정) · 옷장 · MY)를 릴리스 전에 확인하는 목록입니다.
자동화 가능한 항목은 스크립트로 검증하고, 사람이 봐야 하는 항목은 `수동`으로 표시했습니다.

## 소스 구조

`index.html`은 빌드 결과물입니다. 수정은 `src/`에서 하고 `node scripts/build.js`로 다시 만듭니다.

| 파일 | 내용 |
| --- | --- |
| `src/head.html` | 스타일 + 마크업 |
| `src/prelude.js` | 저장 키, 성장(EXP·등급) 규칙, 룩키 캐릭터 관절 좌표 |
| `src/catalog.js` | 121종 상품 카탈로그, 생성 의상 SVG, 실사 의상 앵커 |
| `src/commerce.js` | 가격, 핏 엔진(상품 실측표 × 내 치수 → 부위별 여유 · 추천 사이즈), 후기, 코디 매칭 |
| `src/ar.js` | 포즈 엔진(MediaPipe → MoveNet), 필터·학습, 의상 워핑·소매 리깅, 핏 맵, 룩 앨범, 시연 준비, 체형 측정, 룩키 렌더 |
| `src/app.js` | 상태·화면 렌더·이벤트 |
| `sw.js` | 서비스 워커(빌드 대상 아님): 앱 · 에셋 네트워크 우선, AI 모델 · 엔진 · 폰트 캐시 우선, 시연 준비의 사전 저장 |

## 실행 방법

| 스위트 | 명령 | 범위 |
| --- | --- | --- |
| jsdom 기능 QA | `node scripts/qa-mvp.js` | 구조·삭제 기능, 카탈로그, 탐색, 상세·장바구니, AR 탭, 측정 수식(전신/근거리/반신 판정, 골반 비율 학습), 필터·학습, 핏 엔진·AR 핏 맵, 실사 소매 리깅 좌표, 룩 앨범, 시연 준비 · 오프라인 목록 · 서비스 워커, 측정 효과, 성장, 옷장, MY, 마이그레이션, 초기화 (134개) |
| 화면 감사 | `node scripts/qa-audit.js` | 실제 Chrome에서 16개 화면 순회, 넘침·깨진 이미지·작은 터치 영역·토스트 잘림, AR PC 조작 요소, 실사 소매 픽셀 검사, 새로고침 유지, 창 축소 (85개) |
| AR E2E | `node scripts/e2e-ar.js` | 가짜 웹캠(y4m)으로 MediaPipe 실시간 추적, 떨림, 의상 워핑, PC 조작(칩·버튼·키보드·휠·드래그), 손 제스처·타이머, 룩 앨범 저장, 자동 시작 측정, 사진 → 내 옷 등록(소매 리깅 포함), 측정 효과 카드, 시연 준비(오프라인 저장 포함), 카메라 해제, 룩키 착용, HTTPS LAN 접속, 서버 종료 · 네트워크 차단 후 오프라인 새로고침 (55개) |
| 배포(Vercel) | `node scripts/build.js` 후 `npx vercel deploy --prod --scope fashion18` | https://fashiongame.vercel.app 갱신. GitHub 자동 배포는 연결되어 있지 않음. `.vercelignore`로 `index.html` · `sw.js` · `assets/`만 올림 |
| 로컬 서버 | `node scripts/serve.js [--https]` | http://localhost:8765. `--https`면 https://<와이파이 IP>:8766도 띄움(자체 서명 인증서를 `.cert/`에 자동 생성, openssl 필요) |
| 상품 착용컷 → AR 에셋 | `node scripts/build-garments.js assets/shop/item_9.png:look_e` | 앱과 같은 추출 파이프라인으로 `assets/ar/*.png` 생성 + `AR_PHOTO_ANCHORS` 갱신 |
| 실사 옷 팔 관절 추가 | `node scripts/build-garments.js --rig assets/shop/item_7.png:look_a` | 원본 사진 포즈 → 어깨·골반 4점 닮음변환 → 팔꿈치·손목을 앵커에 추가(PNG는 그대로) |
| 화면 캡처 | `node scripts/shots.js` | 주요 화면 12장 |
| 소매 시각 점검 | `node scripts/probe-arms.js g009` | 팔 포즈 4종 캔버스 캡처 |
| 룩키 착용 점검 | `node scripts/probe-avatar.js [id]` | 코디 세트별 캐릭터 렌더 |

화면 감사와 AR E2E는 `puppeteer-core`, `pngjs`가 필요합니다(기본 위치 `~/.lookfit-tools/node_modules`). 스크린샷은 `~/.lookfit-tools/{audit,e2e,shots,arms}`에 저장됩니다.

## 알려진 한계

- 체형 측정은 2D 카메라 기반 추정입니다. 둘레는 정면 실루엣 폭에 BMI 기반 두께 비율을 곱해 계산하므로 ±4–7cm 오차가 있습니다. 헐렁한 옷을 입으면 더 커집니다.
- "반복 학습"은 신경망 재학습이 아니라, 기기 안에서 사용자 체형 비율(어깨 대비 몸통·골반·다리)을 누적 평균하는 방식입니다.
- 실사 옷 소매 리깅은 2D 분리입니다. 원본 사진에서 팔에 가려진 몸판은 복원할 수 없어 안쪽 원단을 밀어 채우고, 샘플 사진이나 카메라 속 사용자의 원래 팔은 옷 뒤로 비쳐 보일 수 있습니다. 팔 관절 저장 전에 등록한 내 옷은 소매가 따라가지 않습니다(다시 등록하면 됨).
- 핏 엔진의 상품 실측표는 핏 스타일별 여유 규칙으로 만든 값입니다. 실제 브랜드 실측을 넣으면 같은 방식으로 계산됩니다.
- 근거리 측정은 전신 측정을 한 번도 안 했으면 골반 높이 비율 기본값(0.48)을 써서 키 스케일 오차가 약 ±3.5% 더 있습니다. 전신으로 한 번 측정하면 사용자 비율을 학습합니다.
- 사진 → 옷 추출: 위아래가 같은 색(올블랙 등)이면 상·하의를 나누지 못하고 전신 1벌로 등록됩니다. 옷이 팔·가방에 가려진 부분은 비어 보일 수 있습니다.
- 폰에서 자체 서명 인증서(`--https`)로 열면 브라우저가 서비스 워커를 허용하지 않아 오프라인 저장은 PC(localhost)에서만 됩니다. 카메라 · AR은 폰에서도 됩니다.
- 광각(줌 최소) 요청은 카메라가 지원할 때만 적용됩니다. 대부분 PC 웹캠은 화각이 고정이라 약 1.5m 이상 떨어지거나 근거리 모드를 쓰게 됩니다.
